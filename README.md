# 📅 Calendar Booking Backend

A Node.js + Express backend application for managing user meetings and calendar bookings.

## 🚀 Features

- Create a meeting
- Get all meetings
- Get meeting by ID
- Update meeting
- Delete meeting
- User management
- MySQL database integration

## 🛠️ Tech Stack

- Node.js
- Express.js
- MySQL
- REST APIs

## 📁 Project Structure
src/ ├── app.js ├── config/ ├── controllers/ ├── models/ ├── routes/ └── services/

## ⚙️ Installation

1. Clone the repository:
   git clone https://github.com/Indhu2303/calendar-booking-backend.git
2. Install dependencies:
   npm install
3. Create a `.env` file and add:
   PORT = 3000
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=your_password
   DB_NAME=calendar_booking
4. Run the server:
   npm start


## 📌 API Endpoints

### Meetings

- `POST /meetings`
- `GET /meetings`
- `GET /meetings/:id`
- `PUT /meetings/:id`
- `DELETE /meetings/:id`
